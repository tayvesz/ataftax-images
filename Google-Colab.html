Démarrer avec Google Colab

Votre guide essentiel pour coder dans le cloud

1. Qu'est-ce que Google Colab ?

Google Colaboratory, ou "Colab", est un environnement de développement Python gratuit qui s'exécute entièrement dans le cloud. Il permet à quiconque d'écrire et d'exécuter du code via son navigateur. C'est l'outil idéal pour l'analyse de données et le machine learning, car il élimine les barrières techniques et matérielles.

🎉

Gratuit

Accès à des ressources de calcul, y compris des GPU, sans frais.

⚙️

Aucune Configuration

Toutes les bibliothèques populaires sont pré-installées. Codez instantanément.

🚀

Accès aux GPU/TPU

Accélérez vos calculs pour le machine learning en un seul clic.

🤝

Collaboration

Partagez et modifiez vos notebooks en temps réel, comme avec Google Docs.

3. Connecter Google Drive : Votre Espace de Travail

Les fichiers dans une session Colab sont temporaires. Pour un travail durable, il est essentiel de connecter votre Google Drive. Cela vous permet de sauvegarder vos notebooks, de charger vos jeux de données et d'enregistrer vos résultats de manière permanente.

Méthode 1 : Interface Graphique

  • Dans le volet latéral gauche, cliquez sur l'icône Dossier.
  • Cliquez sur l'icône "Monter le Drive".
  • Autorisez l'accès à votre compte Google.
  • Votre Drive apparaît sous /content/drive/My Drive/.

Méthode 2 : Code Python

Exécutez le code suivant dans une cellule pour monter votre Drive :

from google.colab import drive
drive.mount('/content/drive')

Suivez le lien, copiez le code d'autorisation et collez-le dans le champ de saisie.
